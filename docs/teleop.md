# 카메라 원격 조종 (Teleoperation) 가이드

웹캠 앞에서 사람 손을 움직여 3지 다관절 로봇 손(`tri_hand`)을 실시간으로 원격 조종하는 기능입니다. 데이터 글러브나 별도의 마커 없이 일반 RGB 카메라만으로 동작합니다.

시뮬레이션 서버(`src/server.py`)와 실물 제어 서버(`real/server.py`)가 동일한 HTTP REST API 규격을 공유하므로, 대상 서버만 바꾸면 동일한 코드로 가상 모델과 실물 로봇을 모두 제어할 수 있습니다.

---

## 1. 사전 요구사항 및 실행

### 필수 요구사항
* 일반 웹캠 또는 USB 카메라 (노트북 내장 카메라 가능)
* 의존성 패키지 설치 (`mediapipe`, `opencv-contrib-python`)
  ```bash
  pip install -r requirements.txt
  ```

### 실행 방법

1. **제어 서버를 먼저 실행합니다 (둘 중 하나 선택)**:
   ```bash
   # 시뮬레이션 서버
   python src/server.py --headless
   
   # 또는 실물 로봇 제어 서버
   python real/server.py
   ```

2. **다른 터미널에서 카메라 조종 스크립트를 실행합니다**:
   ```bash
   # 1) 기본 웹캠 (0번 카메라)
   python src/teleop.py

   # 2) 외장 웹캠 또는 특정 디바이스 번호 지정
   python src/teleop.py --source 1

   # 3) 녹화된 동영상 파일 재생
   python src/teleop.py --source sample.mp4
   ```

> [!TIP]
> * 처음 실행할 때 Google MediaPipe 손 인식 모델(`src/models/hand_landmarker.task`, 약 9MB)을 자동으로 다운로드합니다.
> * **macOS**: 터미널 앱의 카메라 접근 권한 허용 팝업이 뜨면 승인해야 합니다.
> * **Linux**: 웹캠 디바이스 권한(`ls -l /dev/video*`)이 필요할 수 있습니다 (`sudo usermod -aG video $USER`).
> * 종료하려면 카메라 미리보기 창을 클릭한 뒤 `q`를 누릅니다.

## 2. 실물 로봇 손 카메라 원격 조종 워크플로우

1. **하드웨어 연결**: 모터 12V 전원을 켜고 U2D2를 PC에 연결합니다.
2. **캘리브레이션 확인**: [docs/hardware.md](hardware.md)의 점검 절차를 통해 모터 ID, 영점(`zero`), 회전 방향(`sign`)이 정상인지 확인합니다.
3. **실물 제어 서버 실행**:
   ```bash
   python real/server.py
   ```
   서버 시작 시 전 관절 토크가 켜지고 0.5 rad/s 속도로 부드럽게 0 rad(펼침) 자세로 안전 정렬(Homing)됩니다.
4. **카메라 조종 실행 (새 터미널)**:
   ```bash
   python src/teleop.py
   ```
   웹캠 화면에 초록색 손 랜드마크가 인식되면 로봇 손이 실시간으로 사람 손동작을 추종합니다.
5. **안전 종료**:
   - 미리보기 창에서 `q`를 눌러 카메라 조종을 종료합니다.
   - 서버 터미널에서 `Ctrl+C`를 누르면 모든 모터 토크가 안전하게 꺼지며 종료됩니다.

## 3. 사람 손(5지) ↔ 로봇 손(3지) 관절 매핑 원리

사람 손은 5손가락이지만 `tri_hand`는 3손가락 구조이므로, 사람의 검지·중지·약지 동작을 로봇 손가락 A·B·C에 대응시키고 엄지의 벌림 각도를 대립(Opposition) 관절 `A_j0`에 매핑합니다.

```
       [사람 손]                         [tri_hand 로봇 손]
  엄지 (Thumb Spread)  ─── Yaw 외전 ───>  Finger A 뿌리 관절 (A_j0)
  검지 (Index Finger)  ─── 굴곡/신전 ──>  Finger A 마디 관절 (A_j1, A_j2)
  중지 (Middle Finger) ─── 굴곡/신전 ──>  Finger B 마디 관절 (B_j1, B_j2)
  약지 (Ring Finger)   ─── 굴곡/신전 ──>  Finger C 마디 관절 (C_j1, C_j2)
  새끼 (Pinky)         ─── 미사용 ───>  (사용 안 함)
```

### 상세 관절 매핑표

| 사람 손 동작 | 로봇 관절 | 동작 범위 (rad) | 설명 |
| :--- | :--- | :--- | :--- |
| **검지 첫째 마디 (MCP)** | `A_j1` | 펼침 `0` ~ 오므림 `-0.3` rad | 기본 굽힘 동작 |
| **검지 둘째+셋째 마디 (PIP+DIP)** | `A_j2` | 펼침 `0` ~ 오므림 `-1.2` rad | 손가락 끝 말림 동작 |
| **중지 마디들** | `B_j1`, `B_j2` | 펼침 `0` ~ 오므림 `+0.3` / `+1.2` rad | 하단 우측 손가락 |
| **약지 마디들** | `C_j1`, `C_j2` | 펼침 `0` ~ 오므림 `+0.3` / `+1.2` rad | 하단 좌측 손가락 |
| **엄지 좌우 벌림 (Spread)** | `A_j0` | `-1.0472` ~ `+1.0472` rad (±60°) | 손바닥 기준 엄지 외전/대립 회전 |

> [!NOTE]
> **회전 부호 규칙**: Finger A는 음수(`-`) 방향이 오므림이며, Finger B와 C는 양수(`+`) 방향이 오므림입니다.

## 4. 기구학 계산 및 수식

1. **손가락 굽힘 정규화**:
   - MediaPipe가 반환하는 관절 3D 좌표를 바탕으로 굽힘 각도를 계산하고, `[0 (완전 펼침), 1 (완전 오므림)]` 범위로 정규화합니다.
   - 각 손가락의 닫힘 부호(`CLOSE_SIGN`)와 오므림 기준 각도(`Q_CLOSE`, j1=0.3 rad, j2=1.2 rad)를 곱해 최종 목표 각도를 산출합니다.
2. **엄지 대립(Yaw) 각도 계산**:
   - 엄지 뿌리 뼈가 손바닥 평면 상에서 손목→검지 뿌리 벡터와 이루는 각도를 계산합니다.
   - 손바닥 로컬 좌표계를 기준으로 계산하므로, 손을 앞뒤로 기울이거나 회전해도 값이 왜곡되지 않습니다.
   - 반영 배율은 `YAW_GAIN`이며, `A_j0`의 물리적 한계치인 ±60° (`±1.0472 rad`) 범위 내에서 소프트 리미트가 적용됩니다.

## 5. 내장 안전 인터록 (Safety Features)

1. **지수 평활 및 각속도 제한**:
   - 급격한 손 움직임으로 인한 모터 과부하를 방지하기 위해 목표 각도를 지수 평활(Exponential Smoothing) 필터링합니다.
   - 목표 각도의 변화 속도는 **최대 3.0 rad/s 이하**로 제한됩니다 (XL430 모터 속도 한계인 6.36 rad/s의 약 47%).
2. **손 이탈 시 자세 유지 (Hold Position)**:
   - 웹캠 화면에서 손이 벗어나거나 인식이 일시적으로 끊기면 서버로 새로운 목표 각도를 전송하지 않습니다. 로봇은 즉시 마지막 인식된 안전 자세를 그대로 유지합니다.
3. **엄지 들림 감지 (Out-of-Plane Filtering)**:
   - 엄지를 손바닥 평면 수직 방향으로 약 60° 이상 들어 올리면 평면상 벌림 각도의 신뢰도가 떨어지므로 `A_j0` 목표를 직전 값으로 동결(Freeze)합니다.
4. **손가락 간 접촉 간섭 주의**:
   - 세 손가락을 80% 이상 오므릴 경우(엄지를 크게 벌린 상태에서는 50% 이상) Finger A의 끝단이 Finger B/C와 물리적으로 맞닿습니다.
   - 실물 로봇을 조작할 때는 처음에 천천히 주먹을 쥐어보며 물리적 접촉 시 모터에 무리한 정지 토크가 걸리지 않는지 확인하세요.

## 6. 사용자 맞춤 튜닝 (Calibration)

사람마다 손의 크기나 유연성(손가락이 굽혀지는 정도)이 다르므로, 로봇 손이 완전히 펴지지 않거나 끝까지 오므려지지 않는 경우 [`src/teleop.py`](../src/teleop.py) 상단의 파라미터를 조절할 수 있습니다.

| 파라미터 | 기본값 | 의미 및 조절 방법 |
| :--- | :---: | :--- |
| `HUMAN_RANGE` | `[0.1, 1.4]` | 사람 손가락 굽힘 각도 범위 `[펼침, 최대 굽힘]` (rad)<br>• 끝까지 안 펴질 때: 첫 번째 값을 높임<br>• 끝까지 안 오므려질 때: 두 번째 값을 낮춤 |
| `THUMB_RANGE` | `[0.3, 0.9]` | 엄지 벌림 각도 `[검지에 붙임, 최대로 벌림]` (rad)<br>• 웹캠 미리보기 창의 `thumb spread` 값을 확인하며 범위 설정 |
| `THUMB_SIGN` | `+1.0` | 엄지를 벌릴 때 `A_j0` 회전 방향 (반대로 움직이면 `-1.0`으로 변경) |
