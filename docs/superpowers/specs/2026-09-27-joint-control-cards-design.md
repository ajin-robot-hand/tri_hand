# 관절 조작 카드: 위치/속도 모드와 토크 켜기/끄기

대시보드에서 관절마다 목표를 정해 서버로 보내고, Dynamixel Wizard처럼 위치/속도 모드와 토크 켜기/끄기를 다룬다.

## 목표

- 관절마다 모드(위치, 속도)와 토크 켜짐/꺼짐을 가진다.
- 위치 모드는 목표 각도(rad), 속도 모드는 목표 속도(rad/s)를 받는다.
- 실물 XL430과 같은 순서를 따른다. 토크가 켜져 있으면 모드를 바꿀 수 없다.
- 대시보드 위쪽에 관절 7개를 카드 격자로 보여 주고 조작한다.

범위 밖: 전류 제어 등 다른 모드, 프리셋에 모드 저장, 속도 게인 조정 UI.

## 서버 모델

MuJoCo `<position>` 액추에이터의 토크는 `gain*ctrl + bias1*q + bias2*qdot` 이다 (`gainprm[0]`, `biasprm[1]`, `biasprm[2]`). 모드와 토크 상태에 따라 이 세 값과 `ctrlrange`를 실행 중에 바꾼다.

| 상태 | gainprm[0] | biasprm[1] | biasprm[2] | ctrl 뜻 | ctrlrange |
|---|---|---|---|---|---|
| 토크 꺼짐 | 0 | 0 | 0 | 없음 | 모드 범위 유지 |
| 위치 + 토크 켜짐 | kp | -kp | -kv | 목표 각도 rad | XML의 관절 범위 |
| 속도 + 토크 켜짐 | KVEL | 0 | -KVEL | 목표 속도 rad/s | ±VEL_LIMIT |

- 관절별 설정(`mode`, `torque`, `kp`, `kv`, `torque_limit`)은 파이썬 쪽 한 곳에 두고, 위 표대로 모델 배열에 쓰는 함수 하나로 반영한다. 토크를 끄면 모델의 kp/kv가 0이 되므로 모델 배열을 설정의 원본으로 쓸 수 없다.
- `forcerange`는 모드와 관계없이 ±torque_limit 이다.
- `VEL_LIMIT = 6.36` rad/s. XL430 기본 Velocity Limit 265 × 0.229 rpm ≈ 60.7 rpm (e-Manual 수치, 이번 작업에서 문서 재확인 안 함).
- `KVEL`은 테스트로 정한다. 관절 범위 중간에서 목표 속도 0.5 rad/s에 흔들림 없이 도달하는 값.
- 토크를 켜는 순간 목표를 현재 상태로 맞춘다. 위치 모드는 현재 각도, 속도 모드는 0. 켜는 순간 관절이 튀지 않게 한다.
- `/reset`은 지금처럼 게인을 유지하고, 모드와 토크 상태도 유지한다.

## API

기존 요청은 유지하고 아래를 더한다.

- `GET /state`: `modes` (`"position"` | `"velocity"`), `torque` (bool)를 관절별로 더한다. `targets`는 각 관절 모드 단위의 목표(ctrl)다.
- `GET /joints`: 관절별 `velocity_range`를 더한다.
- `POST /joints/{name}/torque` `{"enabled": bool}`: 상태를 돌려준다.
- `POST /joints/{name}/mode` `{"mode": "position" | "velocity"}`: 토크가 켜져 있으면 409.
- `POST /velocities` `{"A_j2": 0.5}`: `POST /joints`와 같은 검사(알 수 없는 관절 400, 유한하지 않은 값 400). ±VEL_LIMIT로 잘라 적용하고 `applied`, `clipped`를 돌려준다.
- 규칙: 목표 각도 요청(`POST /joints`, `/grasp`, 프리셋 적용)은 위치 모드이면서 토크가 켜진 관절만 받는다. 목표 속도 요청은 속도 모드이면서 토크가 켜진 관절만 받는다. 어기면 409이고 메시지에 해당 관절 이름을 넣는다. `/grasp`와 프리셋 적용은 대상 관절 전체를 검사하고, 하나라도 어기면 아무것도 바꾸지 않는다.

## 대시보드

페이지 순서: 상태 줄, 관절 카드, 그래프, 기존 표와 프리셋.

카드 하나 (시안: 브레인스토밍 `cards-detail-v2.html`):

- 머리: 관절 이름(그래프 선 색), 오른쪽에 "토크" 스위치.
- 모드 버튼 두 개(위치/속도). 토크가 켜져 있으면 잠기고 "토크를 끄면 모드를 바꿀 수 있음"을 보여 준다.
- 목표 슬라이더와 숫자 칸. 범위는 모드에 따라 관절 범위(rad) 또는 ±VEL_LIMIT(rad/s). 슬라이더 위에 현재 값을 가는 세로선으로 표시한다. 토크가 꺼져 있으면 잠기고 "토크가 꺼져 있음. 목표를 보내려면 토크를 켜세요"를 보여 준다.
- 보내는 때: 슬라이더에서 손을 뗄 때, 숫자 칸에서 Enter. 사용자가 만지는 동안에는 서버 값으로 덮어쓰지 않는다.
- 아래 줄: 현재 각도, 속도, 토크. 토크가 한계에 닿으면 주황색.
- 카드 왼쪽 색 띠 = 그래프의 관절 색. 기존 CSS 변수로 밝은/어두운 테마를 모두 지원하고, 휴대폰 너비에서 가로 스크롤이 없어야 한다.
- 서버 오류 메시지는 기존 `#msg`에 보여 준다.

그래프: 목표 점선은 모드를 따른다. 위치 모드 관절은 각도 그래프에, 속도 모드 관절은 속도 그래프에 목표를 점선으로 그린다.

## 검증

- pytest: 토크 켜진 채 모드 변경 409, 토크 끄면 액추에이터 토크 0, 속도 모드에서 목표 속도 도달, 모드가 맞지 않는 목표 요청 409(그리고 상태 불변), 토크 켤 때 목표가 현재 상태로 맞춰짐, 기존 테스트 전부 통과.
- 브라우저: 헤드리스 Chrome으로 대시보드를 열어 카드로 토크 끄기, 속도 모드 전환, 토크 켜기, 목표 속도 보내기를 하고 `/state`와 그래프로 확인. 밝은/어두운, 데스크톱/휴대폰 너비 스크린샷.
