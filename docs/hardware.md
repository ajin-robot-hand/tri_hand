# 실물 하드웨어 연결 및 캘리브레이션 가이드

3지 7자유도 로봇 손(`tri_hand`) 실물 하드웨어의 배선, 모터 세팅, 캘리브레이션 및 제어 가이드입니다.

---

## 1. 하드웨어 구성 및 사양

* **서보 모터**: Robotis Dynamixel XL430-W250-T 총 7개
* **인터페이스**: Robotis U2D2 (USB-to-TTL 컨버터)
* **전원 공급**: DC 12V 5A 안정화 전원 어댑터 (다이지체인 SMPS 전원 케이블)
* **통신 프로토콜**: Dynamixel Protocol 2.0 (기본 보레이트: 1,000,000 bps)

```
[제어 PC] ──(USB)──> [U2D2 컨버터] ──(TTL)──> [모터 1] ──> [모터 2] ── ... ──> [모터 7]
                           │
                     [12V 5A 전원]
```

### 기구학 및 물리 규격
* **모터 최대 토크**: `1.4 N·m` (`forcerange="-1.4 1.4"`)
* **좌표계 및 회전축**:
  - 중력 방향: **`-Y` 축** (`gravity="0 -9.81 0"`)
  - 관절 회전축: **`+X` 축** (`axis="1 0 0"`)
* **오므림(Grasp/Close) 회전 부호 규칙**:
  - **Finger A (상단 3자유도)**: 음수(`-`) 방향 회전이 오므림
  - **Finger B, C (하단 2자유도)**: 양수(`+`) 방향 회전이 오므림

---

## 2. 캘리브레이션 5단계 절차

모터 ID, 통신 속도, 회전 방향(`sign`), 영점(`zero`)은 [`real/config.json`](../real/config.json)에서 관리합니다.

```mermaid
graph LR
    S1["1. 연결 & 스캔<br/>(check.py)"] --> S2["2. ID/방향 확인<br/>(calibrate.py)"]
    S2 --> S3["3. 영점 보정<br/>(center.py)"]
    S3 --> S4["4. 무결성 점검<br/>(check.py)"]
    S4 --> S5["5. 실물 구동<br/>(server.py)"]
```

### 1단계: 하드웨어 연결 및 자동 스캔
모터 전원(12V)과 U2D2를 연결하고 점검 스크립트를 실행합니다. 응답이 없는 모터가 있으면 자동으로 전 보레이트(57,600 ~ 4,000,000)를 스캔합니다.
```bash
python real/check.py
```
> [!NOTE]
> 정상인 경우 7개 모터의 ID, 전압(약 12V), 현재 온도, 동작 모드가 모두 녹색으로 출력됩니다.

### 2단계: 모터 ID 및 회전 방향(sign) 탐색
손가락을 손으로 천천히 움직여 각 관절의 ID 배정과 0점 tick을 확인합니다.
```bash
# 손으로 관절을 하나씩 굽혀가며 ID와 회전 방향을 자동 탐색
python real/calibrate.py

# 또는 실시간 모니터링 모드로 손가락을 움직이며 확인
python real/check.py --watch
```
* **영점(zero)**: 손가락을 완전히 편 상태(0 rad)의 tick 값을 `real/config.json`의 `zero`에 입력합니다 (기본 2048).
* **회전 부호(sign)**: 오므림 회전 시 tick이 감소하면 `sign: -1`로 설정합니다. (Finger A는 음수, Finger B/C는 양수)

### 3단계: 현재 자세를 0 rad로 자동 보정
손가락을 모두 완전히 편 상태에서 아래 명령어를 실행하면 현재 엔코더 위치가 0 rad 기준점으로 자동 저장됩니다.
```bash
python real/center.py --apply
```

### 4단계: 설정 무결성 재점검
```bash
python real/check.py
```
모든 모터가 정상 응답하고 "관절 범위 밖" 경고가 없는지 최종 확인합니다.

### 5단계: 실물 제어 서버 구동
```bash
python real/server.py
```
서버 시작 시 전 관절 토크가 켜지며 **0.5 rad/s 속도로 안전하게 0 rad 위치로 정렬(Homing)**됩니다. (`--no-home` 옵션으로 생략 가능)
정렬이 완료되면 웹 브라우저(`http://127.0.0.1:8000`)에서 슬라이더를 통해 관절을 하나씩 조작해 볼 수 있습니다.

## 3. 제어 스펙 및 게인 단위 차이점

> [!WARNING]
> **시뮬레이션과 실물은 게인의 단위가 완전히 다릅니다.**
> * **시뮬레이션 (`src/server.py`)**: MuJoCo position actuator의 물리 단위 (`N·m/rad`, `N·m·s/rad`)
> * **실물 로봇 (`real/server.py`)**: XL430 모터 내부의 Position P/D Gain **레지스터 정수값** (단위 없음)
> 
> 같은 숫자를 입력해도 동작이 완전히 다르므로 혼용하지 마세요.

| 제어 항목 | 시뮬레이션 (`src/server.py`) | 실물 로봇 (`real/server.py`) | 비고 |
| :--- | :--- | :--- | :--- |
| **목표 각도** | `A_j0`: ±1.0472 rad (±60°)<br>`A_j1~2, B_j1~2, C_j1~2`: ±1.5708 rad (±90°) | 좌동 | 관절 기구학 동작 범위 (`ctrlrange`) |
| **kp (P 게인)** | `0` 초과 ~ `100.0` (기본: `12.0`) | `1` ~ `16383` (정수, 기본: `800`) | 실물은 Position P Gain 레지스터 |
| **kv (D 게인)** | `0.0` ~ `5.0` (기본: `0.5`) | `0` ~ `16383` (정수, 기본: `0`) | 실물은 Position D Gain 레지스터 |
| **토크 한계** | `0` 초과 ~ `1.4 N·m` | `0` 초과 ~ `1.4 N·m` | XL430-W250-T 정격 토크 기준 |

## 4. 내장 안전 인터록 및 비상 정지

1. **가동 범위 및 토크 보호**:
   - 기구학적 가동 범위를 벗어난 목표 각도가 입력되거나 토크가 꺼진 상태에서 명령이 전달되면 HTTP `409 Conflict`로 즉시 거절합니다.
2. **비상 정지 (Emergency Stop)**:
   - 실행 중인 서버 터미널에서 `Ctrl+C`를 누르면 즉시 모든 모터의 토크가 해제(Torque OFF)되며 프로세스가 안전하게 종료됩니다.
3. **과열 방지 및 하드웨어 에러 자동 복구**:
   - 모터 내부 온도가 65 °C를 초과하면 보호를 위해 동작이 중단됩니다.
   - `Hardware_Error` 발생 시 자동으로 모터 Reboot(0x08)를 수행하고 원래 제어 모드/게인/토크를 재설정하여 복구합니다.

## 5. 트러블슈팅 (Troubleshooting)

### Q1. Linux에서 `Permission Denied: /dev/ttyUSB0` 에러가 발생합니다.
* **원인**: 현재 사용자 계정에 시리얼 포트 접근 권한이 없습니다.
* **해결**: 사용자 계정을 `dialout` 그룹에 추가하고 세션을 다시 로그인합니다.
  ```bash
  sudo usermod -aG dialout $USER
  # 변경 후 재부팅 또는 재로그인 필요
  ```

### Q2. WSL2에서 U2D2 장치를 찾지 못합니다.
* **원인**: Windows 호스트에 연결된 USB 장치가 WSL2에 바인딩되지 않았습니다.
* **해결**: Windows 파워셸(관리자 권한)에서 `usbipd` 도구를 사용해 U2D2를 WSL2로 전달해야 합니다.
  ```powershell
  # Windows PowerShell
  usbipd list
  usbipd bind --busid <BUSID>
  usbipd attach --wsl --busid <BUSID>
  ```
  이후 WSL2 터미널에서 `ls -l /dev/ttyUSB*` 명령어로 장치가 잡히는지 확인합니다.

### Q3. `check.py` 실행 시 모터 응답이 없습니다.
1. U2D2의 USB 케이블이 정상 연결되어 있는지 확인합니다.
2. 12V SMPS 전원 공급 장치의 전원 플러그 및 배선 접촉 상태를 점검합니다.
3. 모터의 통신 속도(Baudrate)가 1,000,000이 아닐 수 있으므로 `python real/check.py`의 자동 스캔 결과를 기다려봅니다.
